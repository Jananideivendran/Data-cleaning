Data Cleaning and Preparation Using Microsoft Excel

📌 Project Overview

This project focuses on cleaning, transforming, and preparing a real-world dataset using Microsoft Excel. The main objective is to improve data quality by identifying and handling missing values, correcting inconsistencies, removing duplicate records, and applying appropriate formatting techniques.

🎯 Objectives

Identify and handle missing or blank values.
Correct inconsistent data formats and entries.
Remove duplicate records to maintain data accuracy.
Restructure and organize columns for better readability.
Standardize text fields and data formats.
Apply conditional formatting to highlight important information.
Prepare a clean and structured dataset for further analysis.

🧹 Data Cleaning and Preparation Tasks
1. Handling Missing Values

Identified blank and missing values in the dataset and handled them appropriately to improve data completeness.
In the price column missing values were imputed by MEDIAN value to maintain consistency of data set to maintain relatable.

2. Removing Duplicate Records

Used Excel's Remove Duplicates feature to identify and eliminate duplicate entries.

3. Correcting Inconsistent Formatting

Standardized text entries, date formats, numerical values, and column formatting to maintain consistency.
 In this dataset there are several incorrect texts appeared. These datas were corrected by "Find and Replace" option  

4. Restructuring Columns

Organized and transformed columns to improve the structure and readability of the dataset.

5. Applying Conditional Formatting
Applied Data Bars or Color Scales to the Price column to visualize differences in price values.
Here i am using Data Bars to visualize  price column.
Created a custom conditional formatting rule in the Category column to highlight cells containing Electronics.

7. Final Data Formatting

Adjusted column widths, headings, cell alignment, and number formats to make the cleaned dataset easier to understand and analyze.

📊 Expected Outcome

The final output is a clean, standardized, and well-organized dataset with improved data quality. It is suitable for further analysis, visualization, and reporting.


✅ Conclusion

This project demonstrates practical data cleaning and preparation techniques using Microsoft Excel. By handling missing values, removing duplicates, correcting inconsistencies, restructuring columns, and applying conditional formatting, the dataset becomes more accurate, consistent, and ready for meaningful analysis.
